# TradeGPT V3 — Adaptive Intelligence Engine

TradeGPT V3 is an automated market-discovery and research architecture designed to eliminate manual Qwen discovery/copy-paste workflows.

## Architecture

1. Automated quantitative/event discovery
2. Candidate Union Ledger
3. Adaptive Intelligence Layer
4. Task-specific model routing
5. Empirical model benchmarking
6. Adversarial research/audit
7. Meta Engine risk and quality gates
8. DISCOVERED → WATCH → ARMED → TRIGGERED → TRADE READY state machine
9. Forward-test and discovery-lead-time measurement

## Core principle

AI models are interchangeable research workers. No specific model—including Qwen—is a required architectural dependency. Models are evaluated by task and by observed forward performance.

## Development status

Phase 1 foundation initialized. Market-data adapters, discovery engines, model registry/router, benchmarking, Meta Engine integration, and operational scheduling will be added incrementally with automated tests.

## Risk controls

The system is research/decision-support software. It does not guarantee returns and must not bypass data-verification, liquidity, position-sizing, reward/risk, or portfolio-risk gates.
